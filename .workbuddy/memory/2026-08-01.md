### 任务 4：手机版加 Live2D 数字人 + 自动跳转修复
- **需求**：用户反馈手机打开根 URL 仍显示电脑版界面（混乱），要求手机版也有 Live2D 数字人，功能与电脑版差不多，两版本隔离。
- **问题根因**：`server.js` 第 45 行 `express.static(website)` 在路由之前自动返回 `index.html`，导致 `app.get('/')` 的手机跳转逻辑永远不执行。
- **修复 1：手机 UA 自动跳转**：
  - `express.static` 加 `{ index: false }` 不自动返回 index.html
  - `app.get('/')` 检测 User-Agent（iPhone/Android 等），手机 302 跳转 `/mobile/`
  - 支持 `?desktop=1` 强制电脑版
  - `/mobile` → 301 重定向到 `/mobile/`（确保相对路径 live2d-models/ 正确解析）
- **修复 2：Live2D 数字人集成**：
  - 复制 `vendor/`（cubism SDK）、`live2d-models/`（14MB 模型）、`live2d-integration.js`、`march7th-avatar.png` 到 `mobile-apk/www/`
  - `mobile/index.html` 引入 3 个 Live2D 脚本 + 设置 `GPT_SOVITS_CONFIG = { character: '三月七' }`
  - `mobile.css` 追加 l2d-* 面板样式（适配手机暗色主题：浮窗模式 / 聊天页顶部全宽 / 地图页小浮窗）
  - `mobile-app.js` 集成 Live2D 交互：聊天时 think→say、tab 切换调整面板模式、景点详情语音介绍、最近景点导航语音引导
- **测试结果**：iPhone/Android UA → 302 跳转 ✅；Desktop UA → 200 ✅；Live2D 脚本/模型全部 200 ✅；API health 200 ✅
- **隔离性**：`mobileEnabled` 为 false 时（删 mobile-apk）不跳转，服务器正常启动
