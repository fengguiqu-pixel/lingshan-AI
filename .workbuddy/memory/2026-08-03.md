## 灵山AI导游 APK 构建成功

### 问题修复
- **config.xml 颜色值格式错误**: `BackgroundColor`、`StatusBarBackgroundColor`、`AndroidWindowSplashScreenBackground` 三个偏好值都使用了 `0xff1a1a2e`（Java 整数格式），导致 Cordova 生成的 `colors.xml` 中出现无效的 XML 颜色值，Gradle 构建时 `:app:mergeDebugResources` 任务失败。
  - 修复: 改为 `#FF1A1A2E`（标准 Android XML 颜色格式）
  - 同时手动修复了 `platforms/android/app/src/main/res/values/colors.xml` 中的值
