## 2026-07-20 09:50 - 地图游客位置 + 距离 + 步行导航

### 需求
用户在地图上需要看到"我的位置"水滴标记，并能查看各景点到自己的距离/步行时间。

### 实现
- **HTML** (`index.html`)：在地图区域添加
  - 左下定位按钮（`#locateMeBtn`）— 圆形金色按钮带定位 SVG 图标
  - 绿色"导航到最近"按钮（`#nearestBtn`）— 默认隐藏
  - 顶部状态条（`#locateStatus`）— 显示定位中/成功/错误状态
  - 景点信息浮层中新增"距您 X 米 · 步行约 N 分钟"行（`#mapSpotDistance`）
  - 步行导航按钮（`#mapSpotWalkBtn`）— 拉起腾讯地图 H5 路线页

- **CSS** (`style.css`)：新增
  - `.map-locate-control` / `.map-locate-btn`（含 `locating` 脉冲动画、active 蓝色态）
  - `.map-locate-status`（顶部条，含 success/error 状态色）
  - `.map-spot-card-distance`（绿色距离标签）
  - `.map-spot-card-btn.walk`（绿色步行按钮）
  - `.map-spot-card-item-distance`（景点列表中的距离徽章，最近的标 `nearest` 金色样式）

- **JS** (`app.js`)：新增
  - `DEFAULT_USER_LOCATION` 常量 = `{ lat: 31.4295, lng: 120.0870, name: '灵山胜境主入口' }`（景区北侧主入口，景区内）
  - `haversineDistance(a, b)` — 球面距离公式（Haversine）
  - `formatDistance(m)` — 米/公里格式化
  - `walkMinutes(m)` — 5km/h 估算步行分钟
  - `makeUserLocationSvg()` — 蓝色水滴 SVG（白色内圈 + 阴影滤镜）
  - `addUserLocationMarker(loc)` — TMap.MultiMarker 添加水滴标记 + MultiLabel 文字标签
  - `locateMe()` — 优先 navigator.geolocation，落在 31.40-31.45/120.06-120.12 范围内用 GPS，否则用默认虚拟位置
  - `applyUserLocation(loc)` — 更新标记 + 移动地图 + 刷新距离 + 显示"导航到最近"按钮
  - `navigateToNearestSpot()` — 找最近景点 + 小灵播报 + onMarkerClick 选中
  - `startWalkNavigation()` — 拉起腾讯地图 H5 `https://apis.map.qq.com/uri/v1/routeplan?type=walk`
  - `updateSpotDistances()` — 刷新浮层距离 + 重渲染景点列表（带距离徽章，最近的标金色"最近"）

### 关键坑
- **腾讯地图 MarkerStyle 不支持 HTML 内容**：只能接受图片，所以用 SVG data URI 作为 src
- **TMap.MultiLabel 是可选的**：用 try-catch 包裹避免 SDK 缺失时崩溃
- **Edit 工具替换 `renderMapSpotGrid` 时只匹配到函数签名行**：导致旧函数空壳 + 重复定义，删旧壳 + 删重复 `selectSpot`，手动加回 `onMarkerClick` 头行

### 数据流向
1. 地图初始化 → `addUserLocationMarker(DEFAULT_USER_LOCATION)` 立即在景区内显示水滴
2. 用户点"定位" → 尝试 GPS → `applyUserLocation` → 刷新所有距离
3. 用户点"导航到最近" → 小灵播报 + 自动选中最近景点
4. 用户点景点 → `onMarkerClick` → `updateSpotDistances` 浮层显示步行距离 + "步行导航"按钮
5. 点"步行导航" → 拉起腾讯地图 H5 路线页（含 from/to 坐标）
