# 灵山胜境 AI 导游 — 手机端 PWA 使用说明

## 📱 这是什么？

这是**独立的手机版前端**，专门为手机屏幕重新设计，和电脑版 (`/`) 完全分开。

**不是** 真正的 `.apk` 安装包，但效果接近：
- ✅ 桌面有独立图标（灵山金色莲花）
- ✅ 全屏启动，无浏览器地址栏
- ✅ 底部 Tab 导航（首页 / 地图 / 小灵 / 我的）
- ✅ 启动画面、主题色统一
- ✅ 离线缓存（断网也能看缓存内容）
- ✅ 一键添加到主屏幕
- ⚠️ 需要从浏览器安装，不能从应用商店下载

手机版访问地址：**`http://<电脑IP>:3000/mobile/`**

## 🚀 3 步把手机变成"APP"

### 步骤 1：电脑端启动服务

双击 `灵山AI导游.exe`，命令行会打印局域网 IP，例如：

```
手机/局域网访问 (手机需连同一WiFi):
  [WLAN]  电脑版: http://192.168.1.100:3000/
  [WLAN]  手机版: http://192.168.1.100:3000/mobile/
```

### 步骤 2：手机连同一 WiFi，打开手机版

手机连上**和电脑同一个 WiFi**，打开浏览器（推荐 Chrome / Edge / Safari），地址栏输入：

```
http://192.168.1.100:3000/mobile/
```

> 注意：要加 `/mobile/` 后缀，这才是独立的手机版界面。直接访问 `/` 会进入电脑版。

或者电脑端访问 `http://localhost:3000/qr` 看到引导页，里面有一键复制地址按钮。

### 步骤 3：添加到主屏幕

**iOS Safari：**
1. 点击底部分享按钮（向上的方框）
2. 选择「添加到主屏幕」
3. 确认名称「灵山胜境AI数字人导游」并添加

**Android Chrome：**
1. 浏览器会**自动弹出**「安装应用」或「添加到主屏幕」提示，直接点安装
2. 如果没弹出：右上角菜单 → 「安装应用」或「添加到主屏幕」

之后桌面会出现图标，点击就是全屏 APP 体验 🎉

## 🔧 工作原理

```
┌─────────────────────────────────────────────┐
│  电脑: 灵山AI导游.exe                        │
│  Node.js 服务器, 监听 0.0.0.0:3000          │
└──────────────┬──────────────────────────────┘
               │ HTTP (同一 WiFi)
               ▼
┌─────────────────────────────────────────────┐
│  手机: 浏览器 → PWA 全屏                     │
│  电脑版: http://192.168.x.x:3000/           │
│  手机版: http://192.168.x.x:3000/mobile/    │
└─────────────────────────────────────────────┘
```

**"双端互通"** 的含义：电脑跑后端（必须，因为有 GPT-SoVITS TTS），手机/平板/其它电脑用浏览器访问同一个服务器。

**隔离性**：手机版所有文件在 `mobile-apk/www/` 目录内，与电脑版完全隔离。删除 `mobile-apk/` 文件夹后，电脑版仍然正常运行。

## 🛠 故障排查

### Q1: 手机输入 IP 访问不到？

1. **检查 WiFi 是否同一个**：手机 4G 不行，必须连 WiFi
2. **检查电脑防火墙**：Windows Defender 可能拦截了 3000 端口
   - 解决：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 3000 → 允许
   - 或临时：控制面板 → Windows Defender 防火墙 → 关闭防火墙（仅测试用）
3. **检查 IP 是否正确**：电脑端命令行会显示所有网卡 IP，挑 WiFi 那个（一般是 192.168.x.x），不要用 VMware / VirtualBox 那些虚拟网卡
4. **路由器 AP 隔离**：部分酒店/公共 WiFi 默认开启 AP 隔离，会阻止设备互访，换自己的路由器热点

### Q2: 想要真正的 `.apk` 文件能装到任何手机？

参考同目录下的 `APK编译指南.md`，自行安装 JDK 17 + Android SDK，然后用 Cordova 编译。下载量 1.7GB+，编译时间 20-40 分钟。

### Q3: 怎么更新 PWA？

直接刷新页面即可（PWA 会自动检测新版本）。如果想强制更新：
- iOS：删除主屏幕图标重新添加
- Android：Chrome 菜单 → 卸载后重新访问

## 📁 相关文件

| 文件 | 作用 |
|---|---|
| `website/manifest.json` | PWA 应用清单（图标、名称、主题色） |
| `website/sw.js` | Service Worker（离线缓存） |
| `website/icons/*.png` | 应用图标（7 种尺寸） |
| `website/qr.html` | `/qr` 引导页（显示局域网 IP） |
| `server.js` | 增加了 `/api/network` 和 `/qr` 路由 |
| `launcher.js` | 启动时打印局域网 IP |
| `scripts/generate-icons.py` | 重新生成图标的脚本 |

## 🎨 重新生成图标

如果想改图标设计：

```bash
python scripts/generate-icons.py
```

会重新生成 `website/icons/` 下所有 PNG。
