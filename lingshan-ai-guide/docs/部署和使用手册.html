1. 产品简介

灵山胜境AI数字人导游系统是一款面向无锡灵山胜境景区的智能导览解决方案。系统集成 Live2D 数字人、DeepSeek AI 对话引擎、GPT-SoVITS 语音合成三大核心技术，为游客提供沉浸式智能导游体验。

核心能力

  • 智能对话：基于 DeepSeek Chat 大模型，结合景区知识库增强检索（RAG），实现自然流畅的中文对话。
  • 语音讲解：采用 GPT-SoVITS 语音合成引擎，使用"三月七 March7th v3"声线，为数字人赋予自然动听的声音。
  • 可视化导览：集成腾讯地图，提供景点地图模式与列表模式切换，直观展示景区布局。
  • 数字人交互：Live2D 模型"小灵"拥有 8 种表情、2 组动作，支持口型同步与情绪映射，呈现生动的导览体验。
  • 个性化推荐：根据游客兴趣标签（历史文化、亲子互动、摄影打卡等）智能推荐景点与路线。
  • 管理后台：提供景点管理、知识库管理、数据统计、数字人形象配置等完整后台功能。

适用场景

  • 景区游客自助导览与智能问答
  • 景区运营方内容管理与数据分析
  • 数字化景区建设与智慧旅游展示

3. 快速开始

3.1 启动流程

  1. 双击 灵山AI导游.exe 启动程序。
  2. 启动器自动清理可能残留的 3000 端口占用，随后启动 Node.js 服务器。
  3. 约 3 秒后系统自动打开默认浏览器访问 http://localhost:3000。
  4. 启动成功后，控制台窗口将显示访问地址与运行状态，保持窗口打开即可持续运行。

3.2 手动访问地址

如浏览器未自动打开，可在浏览器地址栏手动输入以下地址：

入口访问地址说明
主前端http://localhost:3000/游客使用的导览主界面
管理后台http://localhost:3000/admin运营管理后台（需登录）
数据大屏http://localhost:3000/admin/visualization数据可视化大屏
健康检查http://localhost:3000/api/health系统运行状态接口

3.3 停止服务

关闭启动器控制台窗口即可停止所有服务。系统会在退出时自动安全关闭数据库连接。

注意：关闭窗口将立即停止服务，所有正在进行的对话与 TTS 合成会中断。请确保无重要操作进行中再关闭。

景点导览模块提供两种浏览模式，游客可在主界面顶部自由切换：

  • 列表模式：以卡片列表形式展示所有景点，包含评分、标签、建议游览时长、最佳游览时间等信息。

每个景点详情页包含以下内容：

5.2 AI对话

AI对话是系统的核心交互功能，由数字人"小灵"作为对话角色，提供自然流畅的智能问答。

使用方式

  • 输入问题：在对话框中输入任意关于灵山胜境的问题，如"灵山大佛有多高？"、"九龙灌浴几点开始？"
  • 快捷问题：点击预设的快捷问题按钮，快速发起常见咨询。
  • 语音播报：AI 回复后可点击播放按钮，通过 TTS 语音合成播报回复内容，数字人将同步进行口型同步与表情变化。
  • 上下文记忆：系统保留最近 10 轮对话历史，支持多轮连续对话。
知识库增强（RAG）：AI 回复前会自动检索景区知识库文档与 FAQ，确保回答准确可靠。若知识库中无相关信息，将基于常识回答并提醒游客联系景区客服确认。

6.2 数据库文件

  • data/lingshan.db — SQLite 主数据库文件，包含 13 张数据表
  • data/lingshan.db-wal — WAL（Write-Ahead Logging）日志文件
  • data/lingshan.db-shm — 共享内存索引文件

数据库采用 WAL 模式运行，支持并发读写，.db-wal 与 .db-shm 为自动生成的辅助文件，请勿手动删除。

6.3 缓存路径配置

7. TTS语音合成配置

TTS 语音合成基于 GPT-SoVITS 引擎，使用"三月七 March7th v3"声线模型，为数字人提供自然流畅的中文语音。

7.1 Python 环境要求

  • Python 3.10 或更高版本
  • PyTorch（支持 CUDA 12.x 的版本，用于 GPU 加速）
  • GPT-SoVITS v2pro 依赖包

系统按以下优先级查找 Python 解释器：

  1. {GSV_DIR}/runtime/python.exe（GPT-SoVITS 内置运行时）
  2. D:\python\python.exe
  3. %USERPROFILE%/anaconda3/envs/gsv/python.exe
  4. %USERPROFILE%/miniconda3/envs/gsv/python.exe
  5. 系统 PATH 中的 python.exe

7.2 GPT-SoVITS 模型加载

系统按以下顺序查找 GPT-SoVITS 目录：

  1. ./GPT-SoVITS-v2pro-20250604-nvidia50
  2. ../Claw/灵山胜境AI导游系统/GPT-SoVITS-v2pro-20250604-nvidia50
  3. ./GPT-SoVITS

找到目录后，系统会加载 tts_worker.py 作为子进程运行，通过 stdin/stdout 进行进程间通信。

8. 常见问题

Q1：启动时提示"端口 3000 被占用"怎么办？

启动器会自动清理 3000 端口的残留进程。若仍被占用，可手动执行：netstat -ano | findstr ":3000" 查看占用进程 PID，再执行 taskkill /F /PID 你的PID 终止进程。或在 .env 中修改 PORT 为其他端口。

Q2：如何重置数据库到初始状态？

停止服务后，删除 data/lingshan.db、data/lingshan.db-wal、data/lingshan.db-shm 三个文件，然后运行 node scripts/init-db.js 重新初始化。注意：此操作会清除所有数据。

Q3：TTS 语音合成不工作（没有声音）怎么办？

① 检查控制台是否输出 [TTS] Worker started successfully；② 确认 GPT-SoVITS 目录存在且包含 tts_worker.py；③ 确认 Python 环境已安装 PyTorch 与 GPT-SoVITS 依赖；④ 查看 [TTS stderr] 错误输出排查具体问题。

Q4：Live2D 数字人不显示怎么办？

① 确认浏览器支持 WebGL（Chrome/Edge/Firefox 最新版）；② 检查 website/live2d-models/ling/ 目录下模型文件完整（含 ling.model3.json、ling.moc3、textures）；③ 清除浏览器缓存后刷新；④ 打开浏览器控制台查看是否有加载错误。

Q5：如何配置 DeepSeek API 密钥？

在系统根目录创建或编辑 .env 文件，添加 DEEPSEEK_API_KEY=sk-你的密钥。API 密钥可在 DeepSeek 开放平台注册获取。配置后重启服务生效。

Q6：管理后台默认账号密码是什么？如何修改？

默认账号 admin，密码 admin123。如需修改，可通过 POST /api/admin/register 创建新管理员，或直接在数据库 admin_users 表中修改密码字段。建议部署后立即修改默认密码。

Q7：AI 对话回复不准确或无法连接怎么办？

① 检查 DEEPSEEK_API_KEY 是否有效；② 确认网络可访问 api.deepseek.com；③ 查看 [TTS stderr] 或 AI API Error 日志。API 不可用时系统会自动降级为本地兜底回复（含票务、景点基础信息）。

Q8：如何上传知识库文档增强 AI 回答？

登录管理后台 → 知识库管理 → 点击"上传文档"，支持 txt、md、docx、pdf、html、json、csv 格式（最大 50MB）。上传后系统自动解析内容存入知识库，AI 对话时会自动检索相关文档（RAG）。CSV 文件会自动导入为 FAQ。

Q9：数字人表情和口型不同步怎么办？

① 在管理后台 → 数字人管理 → 口型同步，调整口型张开灵敏度与平滑系数；② 确认 TTS 音频正常播放；③ 检查表情映射配置是否正确（管理后台 → 数字人管理 → 表情映射）。

Q10：系统启动后浏览器没有自动打开怎么办？

手动在浏览器中输入 http://localhost:3000 访问。若页面无法打开，检查控制台是否显示 一体化服务器已启动，确认服务已正常启动。如启动器报错，检查 runtime/node.exe 与 server.js 文件是否存在。

Q11：如何备份数据？

停止服务后，复制 data/lingshan.db 文件到备份位置即可。如需完整备份，建议同时备份 .env 配置文件与 data/uploads/ 知识库文档目录。WAL 文件（.db-wal）会在服务正常关闭后合并到主数据库。

Q12：GPU 推理未启用，TTS 速度很慢怎么办？

① 确认安装了 NVIDIA 显卡驱动与 CUDA 12.x；② 安装支持 CUDA 的 PyTorch：pip install torch --index-url https://download.pytorch.org/whl/cu121；③ 检查 nvidia-smi 确认显卡可用。CPU 模式下 TTS 约需 64 秒/句，建议尽量使用 GPU。

9. 维护与更新

9.1 数据库备份

建议定期备份数据库，避免数据丢失：

# 1. 停止服务
# 2. 复制数据库文件
copy data\lingshan.db backup\lingshan_20260720.db

# 3. 如需完整备份，同时复制以下内容
copy .env backup\.env
xcopy /E /I data\uploads backup\uploads
建议备份频率：日常运营建议每日备份，重大内容更新前后各备份一次。

9.2 知识库更新

知识库是 AI 对话准确性的关键，建议定期维护：

  • 新增文档：管理后台 → 知识库管理 → 上传文档或手动创建
  • 编辑文档：在知识库列表中点击编辑，修改标题、分类、内容
  • 下架文档：将状态改为"草稿"，AI 对话将不再检索该文档
  • FAQ 维护：管理后台 → FAQ管理，新增/修改常见问题
  • CSV 批量导入：上传 CSV 文件可自动导入为 FAQ（需包含"问题"和"答案"列）

9.3 日志查看

系统日志通过启动器控制台窗口实时输出，主要日志类型：

日志标识说明
[启动]启动器初始化、端口清理、浏览器打开
灵山胜境AI数字人导游系统 v2.0服务器启动成功，显示各入口地址
[TTS]TTS Worker 启动、状态、退出信息
[TTS stderr]TTS 子进程错误输出
AI API ErrorDeepSeek API 调用失败信息
[Server Error]全局错误处理输出
日志保存：控制台日志不会自动保存到文件。如需留存日志，可在启动时重定向输出：灵山AI导游.exe > logs.txt 2>&1。

9.4 系统更新

  1. 停止当前运行的服务
  2. 备份数据库与配置文件
  3. 替换新版本的程序文件（保留 data/、.env、data/uploads/）
  4. 如涉及数据库结构变更，运行 node scripts/setup-all.js 升级表结构
  5. 重新启动服务并验证功能
